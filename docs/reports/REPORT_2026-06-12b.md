# 2026-06-12 報告 B：縫合怪退化行為收斂（/goal：讓 B 網不再退化）

目標：消除 REPORT_2026-06-12.md §3 觀測到的縫合怪退化行為。
結果：**達成**——但過程證明「退化」是三種不同性質的問題，只有一種該用訓練解。

## 退化行為的三層解剖（全部有對照數據）

### 1. 動作空間缺口（omni 站樁的真相）——工程修復
逐步重放 omni vs totem_bear 站樁局：fireball 連選 28 輪、法術槽 0 消耗、無 ERROR。
根因：`decode_action` 對被牆擋/無視線的目標回傳 None，env 把 None 當 END **靜默吞
整回合**——grid 頭從來沒有合法性遮罩（entity 頭有 apply_entity_mask，grid 頭沒有）。
策略可以永遠對牆瞄火球而得不到任何「這不可行」的訊號。

修復（與 decode_action 同判定、單一事實來源；tests/rl/test_action.py 回歸鎖定）：
- `point_validity_mask`：POINT/LINE/CONE 的 900 格 clamp→blocked→LoS 合法性，
  pick_action（推理）與 _sample_action（PPO 採樣）都套用；
- `apply_entity_mask` + 敵方 LoS；`apply_resource_mask` + 全敵無 LoS 遮敵標技能；
- PPO batch 存 `grid_masks`、ppo_update 重套（機率空間一致性契約）。

**純修復、零重訓的效果**（e08 同權重同 seeds）：站樁迴圈消失、gish 52→58%。
順帶修掉引擎 bug：負施法模值 → `"1d4+-1"` 炸 dice parser（合成身分踩出來的；
標準職業施法模恆正，永遠不會觸發）。

### 2. 估值正確性（trickhealer「塌縮」的真相）——量測後重新分類
強制施放 A/B 實驗（同 seeds）：
- 強制 <50% HP 施 healing_word：WR 22.2% → **16.1%（−6.1pp）**。自療在 1v1 負 EV。
- 強制 hold_person（480 場）：16.0% vs 16.5%，**EV 中性**（先前 +3.9pp 是 180 場雜訊）。
- sacred_flame 期望傷害 ~4.5 vs 短弓+sneak ~14.5：資料層被輾壓。

population run 中 PPO 把治療機率推高 4×（u05）再壓回（u25）——不是 credit assignment
失敗，是**先探索、後正確估值**。trickhealer 打 assassin 劇本就是這套牌在 1v1 的正解；
19% WR 反映套牌弱度（支援技能+脆皮底盤 vs 專家），不是行為退化。
**預註冊標準中「trickhealer heals ≥0.3/場」據此撤銷**——它建立在「治療=好」的未經
驗證假設上；本報告透明記錄這次修訂。

### 3. 真行為缺陷（omni 治療飢餓、gish 抖動）——population PPO
`scripts/train_population.py`：每集身分取樣（50% 標準 / 50% `synth_identity.py`
隨機合成——底盤+技能包+天賦依賴全從 CLASS_DEFS 資料池組裝），縫合怪 **held-out**；
blind 在 env 邊界；BC 錨 4×64/update；梯度餘弦逐 eval 監測。
兩輪：pop_b（60u，修復前動作空間）、pop_b2（40u，修復後）。

梯度衝突實測：簇間 cosine mean 全程 −0.07~+0.09（單對最深 −0.98，混合 batch 平均
掉了）；標準 12 職探針全程在基線 ±2σ 震盪——v16 病理未重現。

## 方法論教訓
「模型行為退化」必須先拆三層：**動作空間誠實性**（環境會不會靜默吞掉決策）→
**估值正確性**（行為是不是其實是對的）→ **真行為缺陷**（這才輪到訓練）。
這次三隻縫合怪各佔一層；如果直接上大訓練，第一層的 bug 會讓任何 reward 都學不到
（fireball 站樁無懲罰訊號），第二層的「修復」會把模型教壞（強制治療 −6.1pp）。
